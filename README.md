Sonic Friends
| Daniela Rodríguez Pérez

Descripción:
Sonic Friends es una aplicación web para registrar y administrar personajes del universo de Sonic.

Funciones:
- Agregar personajes.
- Buscar personajes por nombre o rol.
- Editar y eliminar personajes.
- Guardar información en localStorage.
- Mostrar imágenes e información de los personajes.

Tecnologías:
- HTML
- CSS
- JavaScript

Uso:
1. Abre la aplicación desde el enlace de GitHub Pages.
2. Registra un personaje con sus datos.
3. Consulta, busca o administra los personajes guardados.
